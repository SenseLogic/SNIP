In this document, we will go over various code snippets in different programming languages.

Let's begin with a simple C example.

```
/*:test.c*/
#include <stdio.h>

void greet() {
    printf("Hello from a function!\n");
}

int main() {
    greet();
    return 0;
}
```

Here's a simple C++ program that outputs a greeting.

```
//:test.cpp
#include <iostream>
using namespace std;

void greet() {
    cout << "Hello, from C++!" << endl;
}

int main() {
    greet();
    return 0;
}
```

Now, let's take a look at a basic example in C#.

```
//:test.cs
using System;

class Program {
    static void Main() {
        Console.WriteLine("Hello, World!");
    }
}
```

Next, let's try a `Hello, World!` example in Go.

```
//:test.go
package main
import "fmt"

func main() {
    fmt.Println("Hello, World!")
}
```

Let's add an HTML example to create a basic webpage.

```
<!--:test.html-->
<!DOCTYPE html>
<html>
<head>
    <title>Hello World</title>
</head>
<body>
    <h1>Hello, World!</h1>
</body>
</html>
```

Moving on, here is a simple `HelloWorld` class in Java.

```
//:test.java
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

For JavaScript, we will now write a short snippet using the `console.log` method.

```
//:test.js
console.log("Hello, World!");
```

Lua also allows us to easily print a message to the console. Here's a sample.

```
--:test.lua
print("Hello, World!")
```

Let's now see a Python example to print "Hello, World!" using a function.

```
#:test.py
def greet():
    print("Hello, World!")

greet()
```

Now, for Ruby, we’ll use a simple method to print a message.

```
#:test.rb
puts "Hello, World!"
```

Next, we have a SQL query to create a table.

```
--:test.sql
CREATE TABLE users (
    id INT PRIMARY KEY,
    name VARCHAR(100)
);
```

Finally, here's a plain text file example.

```
@:test.txt
This is a plain text file.
It can contain any text without special formatting.
For example:
Hello, World!
```

And that's it! We've covered small snippets across multiple languages.
